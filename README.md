# 安颐居家照护 H5

独立居家照护（上门照护）移动端 H5，视觉与交互延续安颐院内照护 H5。

## 在线地址

**<https://houxueqing.github.io/anyi-home-care-h5/>**

## 产品范围

- 登录注册
- 服务预约：使用额度、服务对象、服务地址（支持定位/地图选点）、服务时间、服务时长、护理员要求、材料收集、联系人
- 我的：订单统计、进行中订单、病历资料、隐私政策
- 我的订单：全部 / 待确认 / 已预约 / 服务中 / 已完成 / 已取消
- 订单详情：进度、护理员、服务对象、服务地址、服务时间、护理员要求、联系人、订单信息
- 居家照护服务详情：适用人群、申请流程、材料审核、服务内容、注意事项
- 病历资料：上传、查看、编辑、删除

## 与合同对应

依据《居家照护（上门照护）服务合作协议-壹账通-0920-修订版》整理：

- 服务内容：5 大类 14 项，含基本生活照护、清洁与卫生、情况观察、专项照护、关怀与陪同
- 申请流程：提交预约 → 材料审核 → 综合评估 → 匹配护理员 → 上门服务
- 服务时效：2 小时响应，24 小时内落实服务、护理员到岗
- 材料：出院小结、出院通知、病历资料、检查报告、身份证明等
- 服务时长：3–7 天，按 24 小时一个服务日
- 使用额度：每次服务消耗 1 次，取消预约返还
- 注意事项：不适用传染性疾病、阿尔茨海默病、精神类疾病等；护理员不提供医疗诊疗

## 演示登录

任意 11 位手机号 + 任意 6 位验证码。

## 本地运行

```bash
cd home-care-h5
python -m http.server 4180 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4180/>。
